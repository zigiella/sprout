Evidencia historica compacta de mediciones relevantes para decisiones de arquitectura.

- aqui va el **hallazgo resumido**
- no va el artefacto bruto generado por herramientas locales

se ignoran via `.gitignore`. Si una corrida importa, se destila aqui en una nota
corta y estable.
