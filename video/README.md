# video/

Produccion del video de 3 minutos de demostracion del proyecto.

## Archivos planificados

- `storyboard.md` — guion visual plano por plano
- `script.md` — voice-over completo en castellano con subs ingles
- `shot_list.md` — lista tecnica de planos a grabar
- `must_have_shots.md` — los 5 planos que no pueden faltar
- `location_notes.md` — Castellar de n'Hug: horarios de luz, permisos, logistica
- `final/` — exports finales (esta carpeta SI se commitea)
- `raw/` — material bruto (en `.gitignore` — demasiado pesado)

## Lo que debe probar el video

1. El sistema funciona offline
2. La IA no es decorativa
3. La seguridad fisica valida o bloquea
4. Pollen cambia el criterio al transportar contexto fresco
5. El sistema detecta caducidad y reacciona con prudencia
6. El sistema escala conceptualmente a una red de parcelas remotas

Todo lo demas es relleno.

## Estructura narrativa propuesta (3 minutos)

| t | Bloque | Contenido |
|---|--------|-----------|
| 0:00-0:20 | Opener | Pyrenees. Metrica de impacto en pantalla. "El agua ya no se pierde solo por escasez..." |
| 0:20-0:50 | Problema + tesis | Parcela sola, decision llega tarde, ausencia como enemigo real |
| 0:50-1:45 | Demo Act 1 | Rhizome solo funciona. Sensores, camara, decision local, seguridad fisica |
| 1:45-2:20 | Demo Act 2 | Pollen llega. Audit en vivo. Contradiction alert. Policy delta |
| 2:20-2:40 | Demo Act 3 | Caso de caducidad. Sistema rechaza contexto viejo |
| 2:40-3:00 | Zoom-out + cierre | Red de parcelas (simulador). Frase final. Logos |
