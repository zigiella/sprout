# Gemma 4 Good Hackathon - Briefing Estrategico

## Datos clave
- **Organizador:** Kaggle + Google
- **Deadline:** 18 mayo 2026 (23:59 UTC) / 19 mayo 01:59 GMT+2
- **Tiempo restante:** ~33 dias desde hoy (15 abril 2026)
- **Prize pool total:** $200,000
- **Submissions por equipo:** 1 unica (editable hasta deadline)

## Tracks y premios

### Main Track ($100K)
- 1er: $50K | 2do: $25K | 3ro: $15K | 4to: $10K

### Impact Track ($50K - 5x$10K)
1. **Health & Sciences** - herramientas para democratizar conocimiento medico
2. **Global Resilience** - respuesta a desastres, clima, edge offline
3. **Future of Education** - agentes multi-tool que adaptan aprendizaje
4. **Digital Equity & Inclusivity** - diversidad linguistica, interfaces intuitivas
5. **Safety & Trust** - transparencia, explicabilidad

### Special Technology Track ($50K - 5x$10K)
- **Cactus** - mobile/wearable con routing inteligente entre modelos
- **LiteRT** - mejor uso de LiteRT de Google AI Edge
- **llama.cpp** - mejor implementacion en hardware limitado
- **Ollama** - mejor proyecto local via Ollama
- **Unsloth** - mejor modelo fine-tuned con Unsloth

> **Combinable:** un proyecto puede ganar Main + Special Tech a la vez.

## Submission requirements
1. **Kaggle Writeup** - max 1,500 palabras, estilo paper/blog
2. **Video YouTube** - max 3 minutos, publico sin login
3. **Repo publico** (GitHub / Kaggle Notebook) - bien documentado
4. **Live Demo** - URL publica o archivos
5. **Media Gallery** - cover image obligatorio

## Criterios de evaluacion
| Criterio | Peso | Que buscan |
|----------|------|-----------|
| **Impact & Vision** | 40% | Problema real significativo + vision inspiradora |
| **Video Pitch & Storytelling** | 30% | Video emocionante, story-driven, bien producido |
| **Technical Depth & Execution** | 30% | Uso innovador de features unicos de Gemma 4, funcional |

## Insights estrategicos

### Lo que claramente quieren
- **Historias humanas con impacto real** (no demos tech por tech)
- **Offline / edge / privacidad** - mencionado explicitamente 3 veces:
  - "classroom with spotty internet"
  - "medical site far from a data center"
  - "community where privacy is non-negotiable"
- **Multimodalidad** - imagen + audio + video + texto
- **Languaje diversity** - tools para comunidades no-anglo
- **Function calling / agentes** - menciona "multi-tool agents"
- **Post-training / domain adaptation** - incentiva fine-tuning

### Stack objetivo para maximizar premios
- **Ollama** (+$10K track) para demo local
- **Unsloth** (+$10K track) si hacemos fine-tuning
- **E2B/E4B** para edge; **26B-A4B** para capacidad sin servidor
- **Video emocional** contando una historia real
